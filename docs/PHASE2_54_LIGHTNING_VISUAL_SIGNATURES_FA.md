# r10.54 — تحلیل نشانه‌های ظاهری صاعقه

- رخدادهای ویدئو با نشانه‌های تصویری تفکیک می‌شوند: کانال باریک قابل‌مشاهده، روشن‌شدن گسترده ابر، فلاش موضعی، خوشه چندپالسی و نامعین.
- گستردگی فضایی از شبکه روشنایی فریم و شواهد کانال از ساختار خطی/DayLine استخراج می‌شود.
- امتیاز «نشانه تصویری» heuristic است و احتمال کالیبره‌شده نیست.
- از ویدئوی RGB به‌تنهایی نمی‌توان قطبیت، نوع دقیق ابر-زمین/درون‌ابری یا مسیر الکتریکی را با قطعیت تعیین کرد؛ UI این محدودیت را صریح می‌کند.
- تست‌های JVM برای فلاش موضعی، روشن‌شدن گسترده و چندپالس اضافه شدند.
