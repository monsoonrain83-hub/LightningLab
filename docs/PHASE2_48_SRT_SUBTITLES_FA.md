# LightningLab r10.48 — ورود زیرنویس SRT

- واردکردن فایل‌های SubRip با انتخاب‌گر اسناد اندروید به ابزار متن ادیتور ویدئو اضافه شد.
- پارسر مستقل و بدون وابستگی خارجی، جداکنندهٔ اعشاری comma/dot، چندخطی، BOM، تنظیمات خط زمان، برچسب‌های متنی ساده و entityهای رایج را پشتیبانی می‌کند.
- cueهای نامعتبر، خارج از طول ویدئو و کوتاه‌تر از حداقل ۲۰۰ میلی‌ثانیه نادیده گرفته می‌شوند.
- هر cue به یک کلیپ متنی قابل‌ویرایش تبدیل می‌شود و از پیش‌نمایش، تایم‌لاین، Undo/Redo و مسیر خروجی موجود استفاده می‌کند.
- پنج تست JVM برای parsing، چندخطی، ورودی نامعتبر، مرتب‌سازی و BOM افزوده شد.
- GitHub Actions اکنون پیش از ساخت APK، `testDebugUnitTest` را اجرا می‌کند؛ بیلد فقط پس از عبور تست‌ها ادامه می‌یابد.
- نسخه: `1.0-r10.48`، versionCode `58`.
