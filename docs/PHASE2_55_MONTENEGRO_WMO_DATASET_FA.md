# r10.55 — مسیر دادهٔ چندناظر WMO

- منبع جدید: Montenegro multi-annotator ground-based sky dataset، شامل ۲٬۵۲۲ تصویر و ۱۱٬۱۹۱ annotation، با مجوز CC BY 4.0.
- سه سر خروجی مستقل CL/CM/CH به‌جای نگاشت اشتباه به ده جنس.
- soft-label از توزیع رأی مشاهده‌گران؛ حفظ اختلاف نظر و کلاس / به‌عنوان «قابل تشخیص نبود».
- تقسیم زمانی بر اساس روزهای متوالی برای کاهش leakage.
- ابزار آماده‌سازی، manifest، گزارش توزیع کلاس و entropy و تست‌های Python.
- مدل آموزش‌دیده و اتصال inference اندروید در این فاز هنوز انجام نشده‌اند.
- DOI: https://doi.org/10.5281/zenodo.21787669
