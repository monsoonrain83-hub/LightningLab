# ممیزی پروژه‌های اطلس و هوش مصنوعی ابر برای Lightning Lab

تاریخ ممیزی: 2026-11-08

## تصمیم معماری

هیچ مدل یا مجموعه‌داده‌ای صرفاً به دلیل داشتن واژه Cloud در نام آن وارد مدل دوربین موبایل نمی‌شود. پروژه به دو دامنه مستقل تقسیم می‌شود:

1. **Ground RGB**: عکس و ویدئوی آسمان از دوربین موبایل؛ تشخیص ۱۰ جنس ابر WMO، سپس مدل‌های مستقل چندبرچسبی برای گونه‌ها/ویژگی‌های ساختاری و مدل تفکیک پیکسل.
2. **Satellite / multispectral**: تصاویر و محصولات ماهواره‌ای و الگوهای سازمان‌یافتگی ابر؛ اطلس و مدل مستقل، بدون ادغام برچسب یا دقت آن با مدل RGB زمینی.
3. **Thermal IR**: تصویر دوربین حرارتی مادون‌قرمز؛ خط مستقل برای تشخیص آسمان صاف/ابری و segmentation، نه جایگزین RGB.

## نکات علمی مهم

- ۴۲ کلاس AICCA کلاس‌های داده‌محور الگوهای ابر ماهواره‌ای هستند؛ معادل ۴۲ جنس/گونه رسمی WMO نیستند.
- Fish / Flower / Gravel / Sugar الگوهای سازمان‌یافتگی ابرهای کم‌عمق دریایی‌اند، نه جنس‌های ابر WMO.
- IRIS-CloudDeep بر تصاویر حرارتی LWIR شبانه از یک دوربین ثابت آموزش/ارزیابی شده؛ تغییر دامنه به RGB روزانه‌ی گوشی نیازمند داده و آموزش جداگانه است.
- Mask R-CNN معرفی‌شده عملکرد محدود گزارش کرده و خود README پروژه نیز افزایش epoch، augmentation و ارزیابی بهتر را از گام‌های بعدی می‌داند.
- برای تشخیص گونه‌ها و ویژگی‌هایی مانند incus، mamma، virga، arcus و asperitas، مدل چندبرچسبی با برچسب‌گذاری مستقل لازم است؛ خروجی مدل ۱۰ جنس به‌تنهایی این ویژگی‌ها را اثبات نمی‌کند.
- مدل آموزش‌دیده نباید ساخته یا ادعا شود مگر فایل وزن واقعی، مجوز، قرارداد ورودی/خروجی، آزمون held-out و معیارهای هر کلاس موجود باشند.

## پیاده‌سازی این مرحله در Android

- صفحه مستقل `Cloud Atlas` به Home متصل شد.
- فهرست ۱۰ جنس ابر و جزئیات دانشنامه‌ای از بانک SQLite آفلاین موجود خوانده می‌شود.
- بخش گونه‌ها، واریته‌ها، ویژگی‌های تکمیلی و ابرهای همراه از بانک دانش محلی استفاده می‌کند.
- بخش AICCA چهار الگوی ماهواره‌ای را به‌صورت دانشنامه‌ای معرفی می‌کند و تفاوت دامنه‌ها/محدودیت دسترسی را آشکارا نشان می‌دهد.
- صفحه اطلس صریحاً می‌گوید محتوای دانشنامه‌ای تشخیص تصویر نیست.
- هیچ تصویر/وزن/کد دارای مجوز نامشخص از مخازن بیرونی کپی نشده است.

## کارهای لازم برای مدل واقعی

1. دریافت و ممیزی دیتاست‌های RGB زمینی با مجوز روشن، حفظ provenance و حذف near-duplicate بین splitها.
2. ساخت baseline MobileNetV2 / EfficientNet-Lite برای ۱۰ جنس، گزارش macro-F1، per-class precision/recall، confusion matrix و calibration.
3. ارزیابی جداگانه روی دوربین‌ها، فصل‌ها، روز/شب، افق/زاویه و اقلیم‌های خارج از داده آموزش.
4. مدل چندبرچسبی ویژگی‌های ساختاری و گونه‌ها با برچسب انسانی؛ خروجی unknown/uncertain الزامی.
5. مدل segmentation مستقل برای ابر/آسمان/مه/غبار/دود/برف؛ قرارداد چندکلاسه و کیفیت ماسک‌ها باید اعتبارسنجی شود.
6. تبدیل TFLite، آزمون quantization و latency/RAM روی دستگاه Android واقعی.
7. AICCA فقط پس از روشن‌شدن دسترسی/مجوز و با شاخه ماهواره‌ای مستقل بررسی شود.
