# LightningLab visual identity - "Storm cinema" (round 6)
- Surfaces: near-black blue (bg #080B11, surface #0F141D, panel #161D2A). Hairline borders (#3A465C @60%), no heavy shadows.
- ONE accent: electric yellow #FFD43B (the bolt) for primary buttons, selected tab/chip/nav, active slider values. Arc blue #6FB4FF only for glow/secondary.
- Type: system sans; weights carry hierarchy (Bold wordmark, SemiBold titles, Normal body). Letter-spacing 0 everywhere (Persian/Arabic joining).
- Shapes: 8/12/16/22/28 dp. Touch targets >= 48 dp (tabs 44 dp, primary buttons 52-56 dp).
- Icons: custom vector set drawn in code (bolt, photo, video, cloud, undo, redo, back, chevron); filled = selected. RTL mirrors back/chevron.
- Motion: screen cross-fade 200 ms, tab content cross-fade 180 ms, tab/colour transitions 160 ms, panel height animates; hero bolt flickers every ~5 s.
- Editors: preview fills the space; tools live in a bottom sheet with tabs (Photo: Light/Color/Detail/Crop/Remove/Save; Video: Cut/Look/Text/Audio/Save), one group visible at a time. Photo: press-and-hold the image to compare with the original.
- Hero artwork (storm cloud, glow, branching bolt) is procedural Canvas code, no image files.
