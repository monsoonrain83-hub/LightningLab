# r10.51 — هیستوگرام RGB و روشنایی

- هیستوگرام ۶۴‌بینی RGB و luma از preview کم‌حجم فعلی محاسبه می‌شود، نه تصویر full-resolution export.
- محاسبه در Dispatchers.Default انجام می‌شود و با تغییر preview/adjustment به‌روزرسانی می‌شود.
- نمودار شیشه‌ای کوچک در گوشهٔ preview قرار می‌گیرد و چهار کانال را نمایش می‌دهد.
- تست‌های JVM برای نرمال‌سازی و تصویر خالی اضافه شدند.
