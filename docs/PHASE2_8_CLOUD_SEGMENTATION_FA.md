# فاز ۲.۸ — زیرساخت جداسازی ابر از پس‌زمینه

## چه چیزی اضافه شده است؟
- بارگذار امن مدل TensorFlow Lite برای جداسازی پیکسل‌های ابر از پس‌زمینه.
- بررسی دقیق شکل و نوع ورودی/خروجی مدل پیش از پذیرش فایل.
- پیش‌پردازش RGB با حفظ نسبت تصویر و حاشیه‌گذاری خاکستری.
- بازنگاشت ماسک به اندازهٔ تصویر اصلی و ساخت پیش‌نمایش قرمز روی نواحی انتخاب‌شده.
- محاسبهٔ درصد پیکسل‌های ماسک‌شده و میانگین امتیاز خروجی.
- واردکردن مدل از حافظهٔ دستگاه با جایگزینی امن؛ در صورت ناسازگاری، مدل قبلی بازیابی می‌شود.
- اجرای کاملاً آفلاین؛ هیچ مجوز اینترنت یا سرویس ابری اضافه نشده است.

## قرارداد فنی مدل
نام فایل هنگام واردکردن: `cloud_segmentation.tflite`

| بخش | قرارداد لازم |
|---|---|
| ورودی | `[1, 256, 256, 3]`، نوع `FLOAT32` |
| ترتیب کانال | RGB |
| دامنهٔ ورودی | اعداد شناور ۰ تا ۲۵۵؛ نرمال‌سازی درون مدل انجام نمی‌شود |
| خروجی | `[1, 256, 256, 1]`، نوع `FLOAT32` |
| معنای خروجی | امتیاز مستقل هر پیکسل برای تعلق به ابر |
| دامنهٔ خروجی | ۰ تا ۱؛ خروجی باید پس از sigmoid باشد |
| آستانهٔ پیش‌فرض | ۰٫۵ |

مدل‌هایی با ابعاد، نوع داده، ترتیب کانال یا دامنهٔ خروجی متفاوت پذیرفته نمی‌شوند. برای سازگاری باید خروجی مدل دقیقاً ماسک تک‌کانالهٔ ۲۵۶×۲۵۶ باشد.

## محدودیت علمی
این فاز **زیرساخت است، نه مدل آموزش‌دیده**. فایل مدل وزن‌دار داخل پروژه قرار نگرفته است؛ بنابراین تا زمانی که مدل سازگار آموزش داده و در برنامه وارد نشود، ماسک جداسازی تولید نخواهد شد. درصد پوشش نمایش‌داده‌شده، درصد پیکسل‌های طبقه‌بندی‌شده توسط مدل است و نباید بدون اعتبارسنجی با مشاهدهٔ اکتا یا پوشش ابری هواشناسی یکی دانسته شود.

ماسک دودویی نیز به‌تنهایی جنس، گونه، ارتفاع، فاز آب/یخ، بارش یا شدت همرفت را تعیین نمی‌کند. این موارد به مدل‌ها و داده‌های جداگانه نیاز دارند.

## راهنمای داده برای آموزش آینده
1. تصاویر آسمان را در شرایط متنوع روز/شب، فصل، زاویهٔ دید، دوربین و پوشش ابری گردآوری کنید.
2. برای هر تصویر یک ماسک هم‌اندازه بسازید: پیکسل ابر = ۱ و پس‌زمینه = ۰.
3. مه، غبار، دود، برف، کوه، ساختمان و بازتاب شیشه را جداگانه برچسب‌گذاری یا از مجموعهٔ آموزش حذف/علامت‌گذاری کنید؛ در غیر این صورت مدل ممکن است آن‌ها را با ابر اشتباه بگیرد.
4. تصاویر یک مکان/زمان را میان آموزش و آزمون پخش نکنید؛ جداسازی مجموعه‌ها باید از نشت داده جلوگیری کند.
5. معیارهایی مانند IoU، Dice، precision، recall و عملکرد جداگانه در شرایط مه/غبار/شب گزارش شود.
6. پس از آموزش، مدل را به قرارداد بالا تبدیل و روی چندین گوشی و تصویر مستقل اعتبارسنجی کنید.

## وضعیت آزمون
ساختار ZIP و وجود فایل‌های مرحله بررسی می‌شود؛ در محیط فعلی ابزار زنجیرهٔ ساخت Android/Gradle در دسترس نیست، بنابراین APK ساخته نشده و اجرای واقعی روی گوشی تأیید نشده است.
