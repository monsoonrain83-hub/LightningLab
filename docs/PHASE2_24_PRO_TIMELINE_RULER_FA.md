# LightningLab r10.45 — تایم‌لاین تعاملی

## تغییرات کاربردی

1. خط‌کش بالای trackها اکنون ورودی لمس و drag می‌گیرد و playhead را با `onMarkerTap` جابه‌جا می‌کند؛ همان مسیر seek قطعه‌محور موجود استفاده می‌شود، بنابراین در پروژه‌های چندقطعه‌ای نیز زمان خروجی به منبع درست نگاشت می‌شود.
2. خط عمودی playhead و tickهای نشانگرها در خط‌کش ترسیم می‌شوند و زمان فعلی/مدت کل هم‌زمان دیده می‌شود.
3. زوم افقی ۱× تا ۴× حفظ شده و دکمهٔ تناسب، نمای کلی را برمی‌گرداند.
4. snapping بازهٔ overlay و effect اکنون به نشانگرهای کاربر و مرزهای خروجی قطعات نیز جذب می‌شود.
5. تابع `TimelineMath.timeAtFraction` نگاشت زمان را مستقل و قابل تست کرده است.

## فایل‌های تغییرکرده

- `Screens.kt`: خط‌کش قابل لمس/کشیدن، نمایش playhead و نشانگرها، کنترل بازگشت زوم.
- `MainVM.kt`: افزودن marker و segment boundaries به snap anchors.
- `Timeline.kt`: تابع نگاشت fraction به زمان.
- `TimelineMathTest.kt`: تست محدوده‌های نگاشت خط‌کش.
- `app/build.gradle.kts`: نسخهٔ 1.0-r10.45 / versionCode 55.

## محدودیت اعتبارسنجی

در این محیط Android SDK و Gradle wrapper در مخزن موجود نیست؛ بنابراین بیلد کامل Android تأیید نشده است. پس از آپلود ZIP، نتیجهٔ GitHub Actions باید بررسی شود و سپس gesture روی دستگاه واقعی آزمایش شود.
