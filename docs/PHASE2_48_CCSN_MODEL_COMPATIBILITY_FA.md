# سازگاری مدل CCSN واردشده توسط کاربر

- فایل \`ccsn_cloud_classification_model.tflite\` که کاربر قبلاً در Library بارگذاری کرده بود، به مخزن عمومی منتقل نمی‌شود؛ مخزن مبدأ \`Slayingripper/Cloud-Classification\` مجوز مشخصی اعلام نکرده است.
- کد trainer آن مخزن از MobileNetV2، ورودی 224×224 RGB و نرمال‌سازی بیرونی \`/255.0\` استفاده می‌کند. ترتیب پوشه‌ها در \`flow_from_directory\` الفبایی است: \`Ac, As, Cb, Cc, Ci, Cs, Ct, Cu, Ns, Sc, St\`.
- مدل در FlatBuffer حداقل runtime نسخه \`2.17.0\` را اعلام می‌کند؛ وابستگی اندروید به 2.17.0 ارتقا یافت.
- CloudClassifier اکنون مدل ۱۰کلاسهٔ جدید را با preprocessing قبلی (حفظ نسبت تصویر، padding خاکستری، RGB خام ۰..۲۵۵) و مدل ۱۱کلاسهٔ CCSN را با resize مربعی و RGB تقسیم بر ۲۵۵ جداگانه اجرا می‌کند.
- Contrail (\`Ct\`) به‌عنوان کلاس دیتاستی مستقل باقی می‌ماند و با ۱۰ جنس طبیعی WMO ادغام نمی‌شود.
- مدل همچنان باید از طریق Import داخل برنامه انتخاب شود؛ تا زمانی که مجوز بازتوزیع روشن نشده، فایل وزن در APK/GitHub bundle قرار نمی‌گیرد.
