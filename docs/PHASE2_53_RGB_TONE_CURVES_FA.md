# r10.53 — منحنی‌های تُن RGB در ادیتور عکس

- منحنی مستقل ۵ نقطه‌ای برای قرمز، سبز و آبی به‌همراه کنترل هم‌زمان RGB.
- LUT با ۲۵۶ سطح برای پردازش سریع preview و export.
- منحنی‌ها non-destructive هستند و داخل پروژهٔ عکس ذخیره می‌شوند.
- پروژه‌های قدیمی بدون کلید منحنی به منحنی identity مهاجرت می‌کنند.
- تست‌های JVM برای identity، جداسازی کانال‌ها، clamp و endpointها.
