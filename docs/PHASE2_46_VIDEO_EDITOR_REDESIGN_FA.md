# LightningLab r10.46 — بازطراحی گردش‌کار ادیتور ویدئو

- نوار ابزار تخت و شلوغ به پنج دستهٔ «برش و تصویر»، «صدا»، «متن»، «لایه‌ها» و «خروجی» تقسیم شد.
- انتخاب دسته، ابزار پیش‌فرض مرتبط را فعال می‌کند؛ تمام ابزارهای قبلی حفظ شده‌اند و از دستهٔ مربوطه در دسترس‌اند.
- تعداد ابزارهای هر دسته کنار عنوان نمایش داده می‌شود تا ساختار پنل قابل فهم‌تر باشد.
- اتصال میان ردیف‌های لایهٔ تایم‌لاین و دسته‌های صدا/متن/لایه‌ها حفظ شد؛ لمس ترک مربوطه، دسته و ابزار متناظر را باز می‌کند.
- پنل همچنان از کامپوننت‌های بومی Compose استفاده می‌کند و وابستگی یا دسترسی شبکه‌ای جدیدی اضافه نشده است.

## محدودیت اعتبارسنجی
این تغییرات باید با GitHub Actions مخزن بررسی شوند؛ در محیط حاضر Gradle wrapper اجرایی/نصب Gradle در دسترس نیست، بنابراین این نسخه را بیلدشده اعلام نمی‌کنیم.
