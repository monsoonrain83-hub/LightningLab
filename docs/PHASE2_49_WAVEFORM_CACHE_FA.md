# r10.49 — cache موج صوتی

- موج‌های PCM واقعی موسیقی و voice پس از decode در LRU thread-safe با ظرفیت ۱۲ منبع و حداکثر ۲۰۴۸ bin نگهداری می‌شوند.
- برای URIهای file، طول و زمان تغییر فایل در کلید cache لحاظ می‌شود تا فایل جایگزین‌شده waveform قدیمی نگیرد.
- تست‌های JVM برای eviction بر اساس LRU و snapshot تغییرناپذیر اضافه شدند.
