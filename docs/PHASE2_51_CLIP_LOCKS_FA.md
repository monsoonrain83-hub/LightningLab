# r10.51 — قفل کلیپ‌های تایم‌لاین

- کلیپ‌های متن/تصویر/استیکر و افکت می‌توانند قفل شوند.
- کلیپ قفل‌شده از drag، trim، حذف، تغییر کنترل‌های overlay و افزودن/حذف keyframe محافظت می‌شود.
- قفل در UI جزئیات کلیپ قابل تغییر است و در Undo/Redo و ProjectCodec v7 ذخیره می‌شود.
- پروژه‌های نسخه‌های ۱ تا ۶ بدون قفل باز می‌شوند و همهٔ کلیپ‌ها به‌صورت پیش‌فرض unlocked هستند.
- نسخه 1.0-r10.51، versionCode 61.
