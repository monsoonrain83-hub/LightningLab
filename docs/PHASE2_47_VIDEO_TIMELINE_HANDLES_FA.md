# LightningLab r10.47 — دستگیره‌های مستقیم تایم‌لاین

- برای لایه‌های متن، استیکر و تصویر، دستگیره‌های چپ و راست به‌منظور کوتاه/بلندکردن مستقیم کلیپ اضافه شد.
- برای کلیپ‌های افکت نیز دستگیره‌های دوطرفه و امکان جابه‌جایی خود کلیپ با drag اضافه شد.
- مقیاس جابه‌جایی اکنون بر اساس عرض کامل تایم‌لاین محاسبه می‌شود، نه عرض خود کلیپ؛ حرکت با زمان واقعی تناسب دارد.
- drag و اسلایدرهای زمان‌بندی در پایان gesture فقط یک نقطهٔ Undo ثبت می‌کنند.
- طول افکت حداقل ۲۰۰ میلی‌ثانیه حفظ می‌شود.
- همهٔ این تغییرات در GitHub Actions با بیلد Android اعتبارسنجی می‌شوند.
