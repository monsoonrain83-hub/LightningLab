# وضعیت مرحله ۲٫۱۷ — Lightning Lab

| بخش | وضعیت |
|---|---|
| رابط و ابزارهای فعلی اپ | حفظ شده از نسخه پایه |
| مدل‌خوان TFLite اندروید | موجود؛ مدل اختیاری از فایل وارد می‌شود |
| ترتیب ده جنس ابر | با قرارداد آموزش یکسان شد |
| خط لوله آموزش | اصلاح و یکپارچه شد |
| ارزیابی هر کلاس و ماتریس اغتشاش | به خروجی آموزش اضافه شد |
| مدل واقعی آموزش‌دیده | هنوز تولید نشده |
| آزمون بیلد اندروید | در این محیط اجرا نشده |

**محدودیت:** این بسته، کد و ابزار آموزش را کامل‌تر می‌کند اما به‌دلیل نبود TensorFlow و عدم امکان دریافت دیتاست در محیط فعلی، وزن مدل را شامل نمی‌شود. هیچ دقتی برای مدل ادعا نشده است.
