# فاز ۲.۱۱ — کنترل کیفیت دیتاست ابر

## هدف
پیش از آموزش U-Net، خطاهای رایج در جفت تصاویر و ماسک‌ها شناسایی شوند تا مدل با داده‌های ناسازگار آموزش نبیند.

## قابلیت‌ها
- ساخت اختیاری `manifest.csv` با تطبیق نام تصویر و ماسک (`*_mask.png`).
- کنترل وجود فایل‌ها و جلوگیری از مسیرهای خارج از پوشهٔ دیتاست.
- بررسی یکسان بودن ابعاد تصویر و ماسک.
- محاسبه درصد پیکسل‌های سفید/ابر در ماسک.
- هشدار برای ماسک‌های خالی، تقریباً تماماً سفید و ماسک‌های چندسطحی.
- یافتن تصاویر تکراری با SHA-256.
- کنترل نشت گروه‌ها بین train، validation و test.
- گزارش CSV برای هر ردیف و گزارش JSON کلی.

## اجرا
```bash
python tools/cloud_segmentation/dataset_qc.py --data cloud_dataset
```
ساخت خودکار manifest:
```bash
python tools/cloud_segmentation/dataset_qc.py --data cloud_dataset --create-manifest
```

## محدودیت
کنترل‌های خودکار فقط ساختار و ویژگی‌های قابل‌اندازه‌گیری فایل‌ها را بررسی می‌کنند. تشخیص اینکه مرز یک ابر نازک یا نیمه‌شفاف درست برچسب‌گذاری شده، همچنان به بازبینی انسانی نیاز دارد. شناسه گروه فریم‌های یک ویدئو نیز باید توسط کاربر یکسان‌سازی شود؛ ابزار از روی نام فایل نمی‌تواند وابستگی زمانی را با اطمینان استنتاج کند.

## وضعیت اعتبارسنجی این فاز
اسکریپت با `py_compile` بررسی شد و روی دیتاست آزمایشی ساختگی اجرا شد. این آزمون فقط عملکرد کنترل کیفیت را بررسی می‌کند و به معنی آموزش مدل یا ارزیابی دقت مدل ابر نیست. APK اندروید در این مرحله ساخته نشده است.
