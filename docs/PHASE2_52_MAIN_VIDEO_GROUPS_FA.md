# r10.52 — Multi-select اصلی ویدئو

- انتخاب چند قطعهٔ اصلی از پنل timeline با checkbox.
- جابه‌جایی گروهی فقط برای انتخاب‌های پیوسته، یک خانه چپ/راست، با حفظ ترتیب داخلی.
- حذف گروهی قطعات انتخاب‌شده بدون ripple؛ عملیات در Undo/Redo ثبت می‌شود.
- انتخاب گروه پس از عملیات منفرد پاک می‌شود تا indexهای stale روی قطعات اشتباه اعمال نشوند.
- helper خالص reorderContiguousGroup با تست مرزها، انتخاب ناپیوسته و حفظ ترتیب.
