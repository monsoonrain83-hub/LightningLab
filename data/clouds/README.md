# Cloud training data directory

Place prepared/licensed training datasets here. The starter CCAiM dataset is not bundled in this source archive; download it with `tools/cloud_ai/prepare_ccaim.py` after reviewing its current license and provenance.

Expected training layout: one folder per class code (`Ac`, `As`, `Cb`, `Cc`, `Ci`, `Cs`, `Cu`, `Ns`, `Sc`, `St`).
