# آموزش مدل جداسازی ابر برای Lightning Lab

این ابزار روی رایانه یا محیطی مانند Google Colab اجرا می‌شود، نه داخل گوشی. خروجی آن مدل آفلاین `cloud_segmentation.tflite` است که با قرارداد فاز ۲.۸ سازگار است.

## ۱) ساختار داده

```text
cloud_dataset/
  images/
    image_0001.jpg
    image_0002.jpg
  masks/
    image_0001.png
    image_0002.png
  manifest.csv
```

برای هر عکس، یک ماسک PNG تک‌کاناله/خاکستری هم‌اندازه بسازید:
- سفید (مقدار ۱۲۸ تا ۲۵۵): ابر
- سیاه (مقدار ۰ تا ۱۲۷): غیرابر
- پیکسل‌های حاشیه‌ای یا نامطمئن را حدس نزنید؛ بهتر است عکس‌های مبهم برای نسخهٔ اول کنار گذاشته شوند.

`group_id` باید برای عکس‌های یک برداشت، یک ویدئو، یک دوربین در یک بازهٔ زمانی یا فریم‌های بسیار مشابه مشترک باشد. جداسازی آموزش/اعتبارسنجی/آزمون در سطح گروه انجام می‌شود تا فریم‌های مشابه به هر سه مجموعه نشت نکنند. می‌توانید ستون `split` را برای همهٔ ردیف‌ها خالی بگذارید تا تقسیم خودکار انجام شود، یا برای تمام ردیف‌ها یکی از `train`, `validation`, `test` را تعیین کنید.

## ۲) نصب و آموزش

Python 3.10 یا 3.11 پیشنهاد می‌شود. در محیط مجازی:

```bash
python -m pip install --upgrade pip
python -m pip install "tensorflow>=2.15,<2.17" "numpy>=1.24" Pillow
python tools/cloud_segmentation/train_cloud_segmentation.py --data cloud_dataset --out out/cloud_segmentation --epochs 45 --batch-size 8
```

اسکریپت، مدل U-Net کوچک را آموزش می‌دهد، بهترین وزن را بر اساس IoU اعتبارسنجی نگه می‌دارد، معیارهای آزمون را ثبت می‌کند و مدل TFLite با ورودی/خروجی float32 می‌سازد.

## ۳) واردکردن در گوشی

فایل `out/cloud_segmentation/cloud_segmentation.tflite` را به گوشی منتقل کنید. در Lightning Lab بخش تحلیل هواشناسی، گزینهٔ واردکردن مدل جداسازی ابر را بزنید و فایل را انتخاب کنید.

## ۴) هشدارهای کیفیت و علم

- دو کلاس فعلی فقط «ابر» و «غیرابر» هستند؛ این مدل به‌تنهایی مه، غبار، دود، برف، کوه یا ساختمان را از هم تفکیک نمی‌کند. برای این کار باید در نسخهٔ بعدی مسئله به چندکلاسه گسترش یابد.
- ماسک‌ها باید با دقت انسانی و معیار ثابت تهیه شوند. مرز ابرهای نیمه‌شفاف ذاتاً مبهم است؛ دستورالعمل برچسب‌گذاری را ثابت نگه دارید.
- مجموعهٔ آزمون باید از مکان‌ها/روزها/دوربین‌های مستقل باشد. دقت خوب روی یک دوربین تضمین تعمیم به دوربین دیگر نیست.
- فقط تصاویری را استفاده کنید که مجوز استفاده و آموزش آن‌ها را دارید؛ منبع، مجوز و شناسهٔ هر مجموعه را جداگانه ثبت کنید.
- درصد پیکسل‌های ماسک‌شده معادل مستقیم oktas یا پوشش ابری دیدبانی نیست.


## ۵) کنترل کیفیت دیتاست (فاز ۲.۱۱)

پیش از آموزش، فایل `dataset_qc.py` را اجرا کنید. این ابزار فقط گزارش می‌سازد و فایل‌های اصلی را تغییر نمی‌دهد:

```bash
python tools/cloud_segmentation/dataset_qc.py --data cloud_dataset
```

اگر هنوز `manifest.csv` نساخته‌اید و نام ماسک‌ها به شکل `sky_0001_mask.png` است، می‌توانید آن را خودکار ایجاد کنید:

```bash
python tools/cloud_segmentation/dataset_qc.py --data cloud_dataset --create-manifest
```

گزارش‌ها در `cloud_dataset/qc_report/` ساخته می‌شوند:
- `qc_report.csv`: وضعیت هر جفت تصویر و ماسک، ابعاد و درصد پیکسل‌های برچسب‌خورده به‌عنوان ابر.
- `qc_report.json`: خلاصهٔ خطاها، هشدارها، فایل‌های بدون جفت و تصاویر تکراری.

این کنترل کیفیت، مواردی مانند نبودن فایل، تفاوت ابعاد تصویر و ماسک، ماسک خالی یا تقریباً کاملاً سفید، سطوح خاکستری اضافی، تصاویر تکراری و نشت یک `group_id` بین مجموعه‌های آموزش/اعتبارسنجی/آزمون را بررسی می‌کند. این ابزار نمی‌تواند درستی علمی مرزهایی را که انسان روی ابر کشیده است تأیید کند.

**مهم درباره group_id:** اگر چند تصویر از یک ویدئو، یک برداشت پیوسته یا یک صحنهٔ تقریباً یکسان هستند، مقدار `group_id` آن‌ها را در `manifest.csv` یکسان کنید. ساخت خودکار manifest برای هر تصویر یک شناسهٔ جدا می‌گذارد و نمی‌تواند رابطهٔ زمانی تصاویر را حدس بزند.

## قرارداد مدل

`float32 RGB [1,256,256,3]` در بازهٔ ۰ تا ۲۵۵، ورودی؛ `float32 [1,256,256,1]` پس از sigmoid در بازهٔ صفر تا یک، خروجی. پیش‌پردازش تصویر باید letterbox خاکستری با مقدار ۱۲۷٫۵ و حفظ نسبت تصویر باشد.

## ابزار ساخت ماسک بدون برنامه‌نویسی

برای ساخت ماسک دستی، فایل `cloud_mask_annotator.html` را در مرورگر باز کنید. راهنمای گام‌به‌گام در `ANNOTATOR_GUIDE_FA.md` قرار دارد. این ابزار مستقل و آفلاین است و خروجی آن با قرارداد ماسک همین اسکریپت آموزش سازگار است.


## آموزش چندکلاسهٔ پدیده‌های جوی

برای آموزش مدل آزمایشی ۷ کلاسه (آسمان صاف، ابر، مه، غبار، دود، برف/یخ، سایر) به `MULTICLASS_DATASET_GUIDE_FA.md` و اسکریپت `train_atmosphere_multiclass.py` مراجعه کنید. این مدل با مدل دودویی فعلی سازگار نیست و هنوز در رابط اندروید اجرا نمی‌شود.

### کنترل کیفیت دیتاست هفت‌کلاسه

برای ماسک‌های چندکلاسهٔ پدیده‌های جوی از گزینهٔ `--multiclass` استفاده کنید تا شناسه‌های ۰ تا ۶ و توزیع هر کلاس بررسی شود:

```bash
python tools/cloud_segmentation/dataset_qc.py --data atmosphere_dataset --multiclass
```
