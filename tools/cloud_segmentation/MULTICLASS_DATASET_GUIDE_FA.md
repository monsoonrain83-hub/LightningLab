# راهنمای دیتاست چندکلاسهٔ پدیده‌های جوی

این مسیر آزمایشی برای آموزش مدل تفکیک پیکسلی هفت‌کلاسه است. مدل فعلی دودویی `cloud_segmentation.tflite` را جایگزین نمی‌کند.

## ساختار پوشه

```text
atmosphere_dataset/
  images/
  masks/
  manifest.csv
```

هر تصویر باید یک ماسک PNG تک‌کاناله با همان ابعاد داشته باشد. مقدار هر پیکسل، شناسهٔ کلاس است؛ ماسک را با قلم نرم یا anti-alias ذخیره نکنید.

| شناسه | مقدار ماسک | کلاس | راهنمای برچسب‌گذاری |
|---:|---:|---|---|
| 0 | 0 | آسمان صاف | آسمان بدون ابر؛ نه ناحیهٔ مه‌آلود |
| 1 | 1 | ابر | قطرات/بلورهای ابر قابل مشاهده |
| 2 | 2 | مه | مه نزدیک سطح زمین یا دید افقی محدود |
| 3 | 3 | غبار | گردوخاک، گردوغبار و هیز معدنی |
| 4 | 4 | دود | ستون یا لایهٔ دود قابل تشخیص |
| 5 | 5 | برف/یخ | برف یا یخِ سطحی قابل مشاهده در صحنه |
| 6 | 6 | سایر | زمین، ساختمان، درخت، آب و هر پس‌زمینهٔ غیرقابل‌طبقه‌بندی در کلاس‌های بالا |

**مرزهای مبهم:** اگر از روی عکس به‌تنهایی نمی‌توان دود را از غبار یا مه را از ابر کم‌ارتفاع تشخیص داد، تصویر را وارد مجموعهٔ آموزشی نکنید یا آن را برای بازبینی انسانی علامت بزنید. برچسب باید بر اساس شواهد تصویری باشد، نه حدس دربارهٔ ترکیب شیمیایی یا ارتفاع.

## فایل manifest.csv

ستون‌های اجباری `image,mask,group_id` و ستون اختیاری `split` هستند. تمام فریم‌های یک ویدئو یا یک برداشت پیوسته باید `group_id` مشترک داشته باشند تا بین train/validation/test پخش نشوند. اگر split را دستی تعیین می‌کنید، همهٔ ردیف‌ها باید آن را داشته باشند.

## اجرا

```bash
python -m pip install -r tools/cloud_segmentation/requirements.txt
python tools/cloud_segmentation/train_atmosphere_multiclass.py --data atmosphere_dataset --out out/atmosphere_multiclass
```

خروجی شامل `atmosphere_multiclass.tflite`، `model_contract.json` و `test_metrics.json` است. این مدل تا زمان اضافه‌شدن اجراکنندهٔ هفت‌کلاسه در اپ اندروید، مستقیماً قابل واردکردن در بخش مدل دودویی نیست.

## حداقل احتیاط علمی

- ۳۰ جفت تصویر فقط حداقل فنی برای شروع آزمایشی است، نه دیتاست کافی برای دقت قابل اتکا.
- برای هر کلاس باید نمونه‌های متعدد، متنوع و مستقل از نظر منطقه، فصل، ساعت، زاویه و دوربین وجود داشته باشد.
- معیار pixel accuracy به‌تنهایی کافی نیست؛ ارزیابی per-class IoU و confusion matrix باید در گام بعد اضافه شود.
- هر نتیجه باید با عنوان «آزمایشی» ارائه شود تا زمانی که ارزیابی مستقل و کافی انجام شود.

## کنترل کیفیت پیش از آموزش
برای بررسی ساختار ماسک‌های هفت‌کلاسه، از حالت چندکلاسهٔ کنترل کیفیت استفاده کنید:

```bash
python tools/cloud_segmentation/dataset_qc.py --data atmosphere_dataset --multiclass
```

در این حالت، شناسه‌های پیکسل باید دقیقاً در بازهٔ ۰ تا ۶ باشند و گزارش، سهم هر کلاس را در کل دیتاست نشان می‌دهد. گزارش ساختاری جای بازبینی چشمی مرزها و صحت علمی برچسب‌ها را نمی‌گیرد.
