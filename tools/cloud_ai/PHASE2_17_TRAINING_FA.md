# Lightning Lab — مرحله ۲٫۱۷: یکپارچه‌سازی آموزش تشخیص جنس ابر

## چه چیزی در این بسته اصلاح شده است؟

- ترتیب کلاس‌های خروجی آموزش با برنامه اندروید یکسان شد: `Ac, As, Cb, Cc, Ci, Cs, Cu, Ns, Sc, St`.
- اسکریپت آموزش اکنون هم پوشه‌های آماده‌شده و هم شناسه دیتاست Hugging Face را می‌پذیرد.
- تقسیم آموزش/اعتبارسنجی/آزمون بر اساس گروه تصاویر کاملاً تکراری انجام می‌شود تا کپی یک تصویر بین دو بخش نشت نکند.
- پیش‌پردازش با اپ هماهنگ است: RGB، اندازه ۲۲۴×۲۲۴، حفظ نسبت تصویر و حاشیه خاکستری ۱۲۷٫۵.
- خروجی ارزیابی شامل `metrics.json`، ماتریس اغتشاش CSV، برچسب‌ها و قرارداد دقیق ورودی/خروجی مدل است.
- فایل TFLite خروجی با نام `cloud_model.tflite` با مدل‌خوان اندروید موجود سازگار طراحی شده است.

## آموزش خودکار از دیتاست آغازین

در محیطی که Python و TensorFlow نصب است:

```bash
pip install -r tools/cloud_ai/requirements.txt
python tools/train_cloud_model.py --dataset serbekun/CCAiM-CloudsDataset --epochs-head 12 --epochs-ft 12 --batch-size 24 --out out/clouds
```

یا اگر تصاویر از قبل در پوشه‌های `Ac/ As/ Cb/ Cc/ Ci/ Cs/ Cu/ Ns/ Sc/ St` هستند:

```bash
python tools/train_cloud_model.py --data data/clouds/ccaim --out out/clouds
```

## خروجی‌ها

- `cloud_model.tflite`: مدل آفلاین برای واردکردن از بخش هواشناسی برنامه
- `metrics.json`: دقت، Macro-F1، گزارش هر کلاس و ماتریس اغتشاش
- `confusion_matrix.csv`: ماتریس اغتشاش قابل بازکردن در Excel
- `labels.txt`: ترتیب خروجی مدل
- `model_contract.json`: قرارداد ورودی/خروجی و پیش‌پردازش

## محدودیت مهم علمی

دیتاست CCAiM کوچک و نامتوازن است. اجرای موفق آموزش به معنی دقت عملیاتی یا توان هشدار سیلاب/رعدوبرق نیست. این مرحله فقط خط لوله اولیه را می‌سازد. پیش از انتشار عمومی باید ارزیابی مستقل بر اساس دوربین/صحنه‌های جدا، افزایش نمونه کلاس‌های کم‌تعداد، بررسی مجوز داده‌ها و کالیبراسیون آستانه عدم‌قطعیت انجام شود. اگر یک عکس برای تشخیص کافی نباشد، برنامه باید نتیجه را نامطمئن اعلام کند.

## وضعیت فایل مدل

در این بسته فایل وزن آموزش‌دیده قرار ندارد. در محیط ساخت فعلی TensorFlow و دسترسی دانلود دیتاست موجود نبود؛ بنابراین تولید فایل ساختگی یا ادعای آموزش موفق انجام نشده است. پس از اجرای اسکریپت، فایل واقعی `cloud_model.tflite` در پوشه `out/clouds` ساخته می‌شود و باید از طریق گزینه واردکردن مدل در اپ انتخاب شود.
